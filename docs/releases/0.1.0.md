# fxguest 0.1.0

**Date:** 12 August 2026  
**Tag:** `v0.1.0`  
**Requires:** [fxlang](https://github.com/ledocorp/fxlang) **v0.9.6+** with **`--cli`** (Win + Linux x86_64)

## Highlights

- First public release of **fxguest** — capability / guest session speech CLI  
- Modes: `allow`, `deny`, `budget` (FuelCap)  
- Dual-path bins: `fxguest` (emit-C) and `fxguest-ir` (IR)  
- No author-written `host/*.c` — rebuild with `fx build fxguest_lib.fx … --cli`  

## Install

Download `fxguest-0.1.0-windows-x86_64.zip` or `fxguest-0.1.0-linux-x86_64.tar.gz` from this release.

## Notes

- Needs an fx package that ships `--cli` + `host/cap` at 0.9.6+.  
- Teaching/demo surface — not a general sandbox product.  
- macOS prebuilts are not claimed.
